# roles/ — 이 프로젝트 고유 규약

`CLAUDE.md`가 매 세션 자동으로 읽히는 진입점이라면, 여기는 **거기서 덜어낸 프로젝트 고유 규약**이다.

| 문서 | 언제 보나 |
|---|---|
| [coding.md](coding.md) | 코드를 쓰기 전. 업데이트 등록·에셋 로드·확장 메서드·비동기·매니저 추가 |
| [model.md](model.md) | 작업을 받았을 때. 어느 모델로 할지 |
| [verification.md](verification.md) | 코드를 고친 뒤. 컴파일 검사·빌드·육안 확인 명령 |

## `process/` 와의 경계

| | `process/` | `roles/` |
|---|---|---|
| 성격 | 어느 프로젝트에서든 통하는 **절차** | 이 프로젝트에서만 참인 **값** |
| 예 | "검증 5단계를 밟고 안 한 건 안 했다고 적는다" | "컴파일 검사는 이 Unity 경로로 이 명령을 쓴다" |
| 이동 | 새 프로젝트에 복사해 그대로 씀 | 복사하면 전부 틀린 값이 됨 |
| 언어 | 영문(`en/`)·국문(`ko/`) 이중 | 국문 단일 |

**절차와 값이 갈리면 `roles/`가 이 프로젝트의 정본이다.** `process/`의 플레이스홀더를 채운 결과가 여기다.

## `CLAUDE.md` 에 남긴 것

전부 덜어내지 않았다. **「반드시 알아야 할 함정」은 `CLAUDE.md` 본문에 남아 있다.**

`CLAUDE.md`만 매 세션 자동으로 읽힌다. 폴더로 빼면 링크를 따라가야 보이는데,
이 프로젝트의 함정은 **안 읽으면 조용히 실패하는** 종류다 — 씬 등록 누락, `#if` 블록,
`UnityEditor` 참조. 전부 컴파일 에러 없이 런타임에 터진다. 자동으로 안 읽히는 순간 방어막이 사라진다.

같은 이유로 프로젝트 소개·코드 규모·문서 링크 표도 남겼다.

## 언어

`CLAUDE.md`와 맞춰 국문 단일이다. `process/`의 en/ko 분리는 "에이전트가 읽는 것 / 사용자가 검토하는 것"을
가르기 위한 것이었고, `roles/`는 이 프로젝트 안에서만 쓰므로 양쪽 유지 비용이 이득보다 크다.

`Desktop/Claude/TXT/Extra Rules.txt`의 "`CLAUDE.md` 편집은 항상 영어로 저장" 규칙을
이 프로젝트에 적용하기로 정해지면([HandOff.md](../HandOff.md) E-1) 그때 함께 따라간다.
