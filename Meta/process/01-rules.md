| `docs/README.md` | 폴더 맵, 부트 시퀀스, "어디를 봐야 하나" 표 |
| `docs/architecture.md` | 초기화 순서, 계층 구조, 공용 패턴 |
| `<도메인별 문서>` | <언제 보는지> |

## 본문에 남길 것 / 빼도 되는 것

| 항목 | 어디에 |
|---|---|
| 프로젝트 고유 함정, 코드 규약, 검증 명령 | **`CLAUDE.md` 본문에 직접** — 매 세션 자동으로 읽힌다 |
| 세션 프로세스, git 규칙, 문서 형식, 모델 규약 | `process/` 로 빼고 링크 — 프로젝트가 바뀌어도 그대로 |
| 작업 명세 템플릿 | `process/04-templates.md` — 필요할 때만 열면 된다 |

`CLAUDE.md`가 길어지면 매 세션 비용이 된다. **프로젝트 고유 정보 밀도가 가장 높은 문서로 유지한다.**
