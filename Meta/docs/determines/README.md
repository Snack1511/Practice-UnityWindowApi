## 작성 규칙

- **결정만 적는다.** 추정은 `(미확정)` 을 붙인다. 근거 없이 단정하지 않는다.
- 결정마다 **날짜와 출처**를 남긴다. 출처는 HandOff 의 결정 번호(C-1 등)나 대화 날짜다.
- 결정이 바뀌면 지우지 말고 `~~취소선~~` + `(변경: 내용, 날짜)` 로 남긴다 — 판단 이력이 남는다.
- 같은 결정을 두 문서에 쓰지 않는다. 다른 폴더에서는 링크만 건다.
