## 장르 — 던전 디펜스 (2026-11-06)

**플레이어는 던전 쪽이다.** 매 주기마다 몰려오는 **용사 파티**를 막아내고,
그들을 자원으로 바꿔 새 유닛 · 함정 · 방 기믹을 배치하며 **던전을 키워나가는 것**이 목표다.

## 핵심 루프 (2026-11-06)

```
광산에 노동자 유닛 배치 → 골드 채굴
        ↓
골드로 저티어 유닛 · 함정 구매/고용 → 던전에 배치
        ↓
주기마다 용사 파티 침공 → 막아낸다
        ↓
마력(소량) + 영혼(처치 수만큼) 획득
        ↓
마력 · 영혼으로 고티어 유닛 · 함정 · 방 기믹 → 던전 성장 → ...

(병행) 유닛으로 부대 편성 → 마을 약탈 → 골드 · 영혼 · 마력 아이템
       마을은 특정 단계를 넘어서기 위한 시험장이다
```

- **방어와 약탈 두 방향이다.** 방어는 주기마다 강제로 오고, 약탈은 플레이어가 고른다.
- 구매는 전부 **상점 시스템**에서 한다 → [02.System](../02.System/README.md).

- **침공 주기는 고정이 아니다.** 회차가 오를수록 점진적으로 빨라지고, 이벤트에 따라 느려지기도 한다.
- 재화 3종(골드 · 마력 · 영혼)의 정의는 [02.System](../02.System/README.md).
- 콘텐츠별 역할은 [03.Content](../03.Content/README.md).

## 개입 — 알림 · 대기 + 스킬 하나 (2026-11-06)

```
침공 임박 → 알림 → 대기 → 침공 시작 → 전투는 자동
                                  └ 플레이어는 유저 스킬 1개를 마우스 클릭으로 사용
```

- 전투 자체는 자동이다. 배치 · 구매 · 약탈 편성은 침공 밖에서 한다.
- 침공 직전에 **알림**을 띄우고 **대기**한다. 갑자기 시작되지 않는다.
  - 대기는 **정해진 시간**이다. 지나면 자동으로 시작한다 — 자리를 비워도 방어는 자동으로 진행되고 스킬만 못 쓴다.
  - 플레이어가 누르면 **바로 시작**한다 (조기 시작).
- 침공 중 플레이어가 할 수 있는 건 **유저 스킬 하나를 클릭으로 쓰는 것**이다.

> **기술 영향** — 클릭 통과가 켜져 있으면 스킬 클릭이 게임에 닿지 않는다.
> 침공 중에는 클릭 통과를 끄거나, "그려진 곳만 클릭을 받는" 히트 테스트가 필요하다 →

## 패배 — 손실만 있다 (2026-11-06)

- 용사 파티를 막지 못해도 **게임 오버는 없다.** 손실을 입고 게임은 계속된다.
- 띄워두고 잊어버려도 망하지 않는 게임이어야 한다 — 오버레이로 다른 작업 중에 켜두는 게임이라서.
- 따라서 **한 판은 끝이 없다.** 세이브는 하나의 진행이 계속 이어지는 구조다.
