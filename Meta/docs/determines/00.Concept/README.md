# 00. Concept — 프로젝트 기획 컨셉

## 확정

- **프로젝트명: 데스크탑 던전 (DesktopDungeon).** 약칭 `ProjectDD`. 이 저장소(`Practice-UnityWindowApi`)는 그 전신을 잇는 연습 프로젝트다.
  전신 자료는 2025-09 의 `ProjectDD MainProcess API문서.drawio` 하나가 확인됐다 — 매니저 초기화 순서 다이어그램이라 기획 내용은 없다.
- **데스크톱 오버레이 게임.** 테두리 없는 최상위 창이 작업 영역을 덮고, 그리지 않은 픽셀은 투명해서 바탕화면이 비친다.
  구현은 [window-native.md](../../window-native.md).
- **다른 작업을 하면서 띄워두는 게임.** 클릭 통과로 아래 프로그램을 그대로 쓸 수 있다.
- **핵심 루프는 획득 → 소비 → 강화.** 던전·광산에서 얻고 마을에서 쓴다. 상세는 [03.Content](../03.Content/README.md).

## 미확정

- (미확정) 장르 — 로드맵의 오브젝트 구성(스크롤 배경 · 이동 캐릭터 · 전투단 · 배낭 격자 · 이벤트)으로 보아
  **캐릭터가 화면을 가로질러 자동 진행하는 방치형 모험**으로 읽힌다. 사용자 확인 전이다.
- (미확정) 플레이어 개입 수준 — 완전 자동인지, 이벤트마다 선택하는지.
- (미확정) 한 판의 단위 — 끝이 있는 런인지, 끝없이 이어지는 진행인지.
