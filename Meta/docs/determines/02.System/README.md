# 02. System — 시스템 정의

여러 콘텐츠가 같이 쓰는 기능이다. 계층 규칙은 [roadmap.md](../../roadmap.md) §1 —
**여러 콘텐츠가 동시에 필요로 하면 시스템**이다.

## 인벤토리 시스템

던전 · 광산 · 마을이 모두 쓰므로 모듈이 아니라 **시스템**이다 (C-1 결과).
경제 시스템은 따로 두지 않는다 — 재화가 아이템이므로 인벤토리가 다룬다 (C-4).

### 아이템 (C-4, 2026-10-29)

```
Item { id, type, count }
  type: Equipment | Consumable | Currency
```

- **재화는 아이템의 한 타입(`Currency`)이다.** 골드 · 광석 · 보석 등 재화가 여러 종일 수 있다.
- **보상 · 소모는 아이템 단위로만 지급·소모한다.** 재화인지 따지지 않는다.

```
Give(itemId, n)   // 보상 모듈
Take(itemId, n)   // 소모 모듈
```

### 보관 위치 — 목록형 (2026-11-06)

**배낭은 없다.** 인벤토리는 격자 없이 **종류별 개수만** 쌓는 목록형 보관함이다.

| 칸 | 담는 것 | 형태 |
|---|---|---|
| **아이템 목록** | 재화가 아닌 아이템. 지금은 `마력 아이템` 하나뿐 | 종류별 개수 |
| **재화 칸** | `Currency` (골드 · 마력 · 영혼) | 종류별 개수 |

`Give` / `Take` 는 아이템 타입을 보고 **인벤토리가 칸을 고른다.** 호출하는 쪽은 칸을 모른다.

> ~~배낭 격자에 `Equipment` · `Consumable` 이 칸을 차지한다~~ (변경: 목록형, 2026-11-06)

### 격자는 던전 배치에 쓴다 (2026-11-06)

격자 개념은 배낭이 아니라 **던전 안에 유닛 · 함정 · 방 기믹을 배치하는 데** 쓴다 → [03.Content](../03.Content/README.md).

### ~~배낭 표시 — UI (C-2, 2026-10-29)~~ (변경: 배낭 폐기, 2026-11-06)

방치형 모험 전제에서 정한 결정이다. 장르가 던전 디펜스로 바뀌며 배낭이 없어졌다.
당시 근거(격자 · 드래그 · 하이라이트는 UI 가 잘한다, 클릭 판정 경로를 하나로)는 **던전 배치 격자를 UI 로 그릴지 정할 때** 다시 쓸 수 있다.

## 재화 3종 (2026-11-06)

재화는 위 C-4 대로 아이템의 `Currency` 타입이다. 종류는 셋이다.

| 재화 | 등급 | 얻는 곳 | 쓰는 곳 |
|---|---|---|---|
| **골드** | 1차 | 광산 — 노동자 유닛이 채굴 · 마을 약탈 | 모든 구매의 기본 비용. 저티어 유닛 · 함정은 골드만으로 산다 |
| **마력** | 2차 | 용사 파티 방어 성공 시 소량 · 약탈한 아이템에서 추출 | 고티어 유닛 · 고티어 함정 · 방 기믹을 살 때 **골드에 더해** 낸다 |
| **영혼** | 태그 | 용사 파티 방어 시 처치한 수만큼 · 마을 약탈 | **특정 태그**가 붙은 것을 살 때 추가로 낸다 |

### 구매 비용 구조

```
비용 = 골드
     + 마력   (고티어이거나 방 기믹이면)
     + 영혼   (영혼 요구 태그가 붙어 있으면)
```

**영혼을 요구하는 태그:**

| 대상 | 태그 |
|---|---|
| 유닛 | `언데드` · `유령` |
| 함정 · 방 기믹 | `정신계` |

> ~~(미확정) 재화 종류 목록 — 골드 · 광석 · 보석은 예시다.~~ (확정: 골드 · 마력 · 영혼, 2026-11-06)

## 상점 시스템 (2026-11-06)

**재화를 쓰는 곳은 콘텐츠가 아니라 시스템이다.** 상점 시스템과 재화 소모 · 보상 처리 흐름으로 표현한다.

상점 UI 는 탭 4개다. 탭을 누르면 해당 패널로 바뀌고 살 수 있는 것을 보여준다.

| 탭 | 내용 |
|---|---|
| 유닛 | 유닛 고용 |
| 함정 | 함정 구매 |
| 기믹 | 방 기믹 구매 |
| 관리 | (미확정) |

- 구매 비용은 위 「구매 비용 구조」를 따른다.
- 소모는 상점이 `Take`, 보상은 각 콘텐츠가 `Give` 로 인벤토리를 거친다 (C-4).

## 마력 아이템 (2026-11-06)

마을 약탈로 얻는 아이템이다. **마력을 추출할 수 있다.**

- **약탈 아이템은 전부 `마력 아이템` 하나로 통합한다.** 기능상 종류가 나뉘지 않는다.
- **겉모습만 무작위다.** 얻을 때마다 이미지 풀에서 무작위 이미지를 골라 보여준다. 이미지는 연출일 뿐 효과 차이가 없다.

- (미확정) 추출하는 곳과 방법 — 상점 「관리」 탭인지, 따로 있는지.
- (미확정) 추출 외 다른 쓰임이 있는지 (장착 · 판매).

## 태그 (2026-11-06)

유닛 · 함정 · 방 기믹에 붙는 분류다. 지금 확인된 역할은 둘이다.

| 태그 | 붙는 대상 | 효과 |
|---|---|---|
| `노동자` | 유닛 | 광산에 배치할 수 있다 → 골드 채굴 |
| `언데드` · `유령` | 유닛 | 구매 시 영혼 요구 |
| `정신계` | 함정 · 방 기믹 | 구매 시 영혼 요구 |

여러 콘텐츠가 같이 보는 분류이므로 시스템에 둔다.

## 미확정

- ~~(미확정) 배낭이 아직 있는가~~ (확정: 없음. 격자는 던전 배치로, 2026-11-06)
- (미확정) 아이템 타입 목록 — `Equipment` · `Consumable` 은 방치형 모험 전제의 예시였다. 지금 재화 외 아이템은 `마력 아이템` 하나다.
  다른 아이템이 생기지 않으면 `Item.type` 구분은 `Currency` / `마력 아이템` 둘로 충분하다.
- (미확정) 마력 아이템 이미지의 무작위가 RNG 정책(C-3, 상태 저장)을 따르는지 — 연출용이면 `UnityEngine.Random` 으로 충분하다 ([01.Policy](../01.Policy/README.md) 는 연출용 허용).
- (미확정) "처치한 유닛 수만큼의 영혼" — 처치한 **용사** 수로 읽었다. 확인 필요.
- (미확정) 티어 구분 — 몇 단계이고, 어디부터 마력이 필요한지.
- (미확정) 유닛 · 함정 · 방 기믹이 각각 무엇인지 — 방 기믹은 방 하나 전체에 거는 효과인지.
