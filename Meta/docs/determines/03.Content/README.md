# 03. Content — 콘텐츠 정의

## 3종이 역할을 나눈다 (C-1, 2026-10-29)

| 콘텐츠 | 역할 | 소유 모듈 |
|---|---|---|
| `ContentDungeon` 던전 | 전투로 아이템 획득 | 타임라인 · RNG · 보상 |
| `ContentMine` 광산 | 방치형 자원 채집 | 타임라인 · RNG · 보상 |
| `ContentVillage` 마을 | 상점 · 강화로 소비 | 소모 |

```
던전 / 광산 → 획득 → 마을 → 소비 → 강화 → 던전 / 광산 ...
```

- 인벤토리는 3종이 모두 쓰므로 모듈이 아니라 시스템이다 → [02.System](../02.System/README.md).
- 광산은 무작위 결과를 쓰므로 RNG 를 소유한다 → [01.Policy](../01.Policy/README.md).
  (C-1 선택지 원안에는 광산 RNG 가 없었으나, C-3 에서 광산 RNG 상태를 저장하기로 하면서 포함됐다.)
- 콘텐츠 오브젝트는 런타임에 생성한다 → [01.Policy](../01.Policy/README.md).

코드 구조(`ContentManager` · `ContentObject` · `ContentBase`)는 [scene-and-content.md](../../scene-and-content.md) §7.

## 미확정

- (미확정) 콘텐츠 사이 이동 방식 — 플레이어가 고르는지, 배낭이 차면 자동으로 마을에 가는지.
- (미확정) 광산의 방치 방식 — 다른 콘텐츠를 하는 동안에도 채집이 진행되는지, 게임을 끈 동안에도 쌓이는지.
- (미확정) 마을에서 강화하는 대상 — 캐릭터 · 장비 · 배낭 중 무엇인지.
