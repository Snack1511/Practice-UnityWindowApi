# 03. Content — 콘텐츠 정의

## 콘텐츠별 역할 (2026-11-06 갱신)

장르가 던전 디펜스로 확정되면서(→ [00.Concept](../00.Concept/README.md)) C-1 의 역할 정의가 바뀌었다.

| 콘텐츠 | 역할 | 얻는 재화 | 소유 모듈 |
|---|---|---|---|
| `ContentDungeon` 던전 | 유닛 · 함정 · 방 기믹을 배치하고, 주기마다 오는 용사 파티를 막는다 | 마력 · 영혼 | 타임라인(침공 주기) · RNG · 보상 |
| `ContentMine` 광산 | `노동자` 태그 유닛을 배치해 골드를 채굴한다 | 골드 (무작위 변동 있음) | 타임라인 · RNG · 보상 |
| `ContentVillage` 마을 | 부대를 보내 약탈하는 대상. **특정 단계를 넘어서기 위한 시험장** | 골드 · 영혼 · 마력 아이템 | RNG(시뮬레이션) · 보상 |

### 던전 배치 격자 (2026-11-06)

던전 안은 **격자**다. 유닛 · 함정 · 방 기믹을 격자 칸에 배치한다.

- (미확정) 격자 단위 — 칸 하나가 방 하나인지, 방 안을 다시 칸으로 나누는지.
- (미확정) 격자를 UI 로 그릴지 월드 오브젝트로 그릴지 — C-2 의 판단 근거를 다시 볼 것 → [02.System](../02.System/README.md).
- (미확정) 격자 크기와 확장 방식 — 던전이 커진다는 게 칸이 늘어나는 것인지.

### 침공 주기

- 회차가 오를수록 **점진적으로 빨라진다.**
- 이벤트에 따라 **느려지기도 한다.**
- 주기 관리는 던전의 타임라인 모듈이 맡는다.

### 마을 약탈 (2026-11-06)

던전 방어의 반대 방향이다. 방어는 용사가 오는 것이고, 약탈은 내가 나가는 것이다.

- 마을은 **여러 개**다. 그중 하나를 골라 **여러 유닛으로 이루어진 부대**를 보낸다.
- 성공하면 **골드 · 영혼**을 얻고, **마력 아이템**을 약탈한다 → [02.System](../02.System/README.md).
- **약탈당한 마을은 방어도가 오른다.** 침공 한 번마다 오른다.
  방어도가 오르면 그 마을은 방어 유닛을 더 배치하고 방벽을 세운다.
- 역할은 **시험장**이다. 특정 단계를 넘어서려면 마을 약탈을 거쳐야 한다.
- **전투는 간략 시뮬레이션이다.** 실시간으로 그리지 않고, 대략적인 과정과 결과 화면만 보여준다.

```
부대 편성 → 마을 선택 → 시뮬레이션 → 과정 요약 + 결과 화면
                                   ↓
                     골드 · 영혼 · 마력 아이템 획득
                     그 마을 방어도 +1 (방어 유닛 · 방벽 증가)
```

> ~~(미확정) 마을의 역할~~ (확정: 약탈 대상 · 시험장, 2026-11-06)

- 인벤토리는 3종이 모두 쓰므로 모듈이 아니라 시스템이다 → [02.System](../02.System/README.md).
- 무작위를 쓰는 콘텐츠는 **셋 다** 각자 RNG 를 소유한다 → [01.Policy](../01.Policy/README.md).
  던전은 침공 · 이벤트, 광산은 채굴량, 마을은 약탈 시뮬레이션.
- 콘텐츠 오브젝트는 런타임에 생성한다 → [01.Policy](../01.Policy/README.md).

코드 구조(`ContentManager` · `ContentObject` · `ContentBase`)는 [scene-and-content.md](../../scene-and-content.md) §7.

## 미확정

- (미확정) 시험장이 막는 "특정 단계"가 무엇인지 — 던전 회차인지, 티어 해금인지. 어느 마을을 몇 번 약탈해야 넘어가는지.
- (미확정) 약탈 실패 시 — 보낸 부대가 사라지는지, 일부만 돌아오는지.
- (미확정) 마을 방어도가 내려가는 경우가 있는지 (시간 경과 등).
- (미확정) 부대로 보낸 유닛이 그동안 던전 방어에서 빠지는지.
- ~~(미확정) 광산 RNG~~ (확정: 채굴에 무작위 있음. 광산이 RNG 소유, 2026-11-06)
- (미확정) 광산 무작위의 형태 — 채굴량이 흔들리는지, 가끔 대박이 나오는지.
- (미확정) 광산의 방치 방식 — 던전을 보는 동안에도 채굴이 진행되는지, 게임을 끈 동안에도 쌓이는지.
- (미확정) 노동자 유닛이 던전 방어에도 쓰이는지, 광산 전용인지.
