## 문서 작성 규칙

- 파일명: `NNN-주제.md` (3자리 일련번호, 재사용 금지)
- 각 항목: **현상 → 근거(`파일:줄`) → 영향 → 권장** 순서. 근거 없는 항목은 넣지 않는다.
- 해결된 항목은 삭제하지 말고 `~~취소선~~` + `✅ 해결 (커밋 해시)` 표기 → 판단 이력이 남는다.
- 이 README의 문서 목록 표를 항상 함께 갱신한다.
